# Cursor Hackathon Simplicity Pack

This bundle contains:
- `.cursor/skills/boring-engineering/SKILL.md` — the Boring Engineering Agent Skill (v1.1.0), adapted from the upstream repository.
- `.cursor/rules/hackathon-simplicity.mdc` — additional always-on Cursor project rules tailored for hackathons.
- `LICENSE` — upstream MIT license.

## Install

1. Unzip this folder.
2. Copy the `.cursor` folder into the root of your hackathon project (merge with an existing `.cursor` folder; do not overwrite your existing rules).
3. Open the project in Cursor.
4. Start a new Agent chat and ask it to inspect the Boring Engineering skill and project rules before implementing.

The skill is based on:
https://github.com/alvindemesadev/boring-engineering

Upstream skill version: 1.1.0

Note: This bundle includes the core SKILL.md only, not the upstream repository's optional reference, asset, or example files. The core skill remains usable without them.
